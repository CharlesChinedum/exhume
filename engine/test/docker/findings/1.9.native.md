## Does forge stop the campaign at the first failure?
- Time to first failure without shrinking: early 0.11 s, rare 0.17 s, against 1.27 s for a full 256 x 64 campaign with no failure. Stops at first failure (early fails sooner than a full campaign): **yes**. A failing campaign therefore costs the calls up to the first failing run plus shrinking.

## Effect of --fuzz-seed fixed vs unset

- early: fixed seed 0.13 s; unset seed runs: 0.11 0.11 0.17 s (statuses: Failure Failure Failure).
- rare: fixed seed 0.17 s; unset seed runs: 0.18 0.18 0.17 s (statuses: Failure Failure Failure).
- never: fixed seed 1.27 s; unset seed runs: 1.26 1.26 1.27 s (statuses: Success Success Success).
- Observation during development (an earlier, rarer variant of the rare condition with one more receiver constraint, about 1e-4 per call): repeated `--fuzz-seed 42` invocations of the same campaign were not always identical (one invocation failed at run 33, the next invocations of the same command passed all 256 runs). A fixed seed therefore does not guarantee that a rare witness is reproduced across invocations in forge 1.5.1. Only the shipped rare condition is measured by this script.
